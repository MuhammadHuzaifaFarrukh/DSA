Implementing a Queue using a Linked List is a common alternative to an array-based implementation. While your previous version used a dynamic array that occasionally required a reserve operation to resize, a Linked List-based queue can grow and shrink one element at a time without needing to copy the entire container to a new memory location.

In this implementation, push (enqueue) happens at the Tail, and pop (dequeue) happens at the Head.
