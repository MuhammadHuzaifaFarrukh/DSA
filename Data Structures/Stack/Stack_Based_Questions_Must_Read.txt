What is a Stack? (The LIFO Principle)
Imagine a stack of physical plates in a cafeteria.
You always place a new plate on the top.
If you want to take a plate, you take the one from the top.
You cannot (safely) grab a plate from the middle or the bottom without removing everything above it first.


// You might ask: "If a Vector can do everything a Stack can, why use a Stack?"
// The answer is Safety and Intent.
// Using a Stack ADT tells other programmers (and the compiler) exactly how the data should be handled.
// It prevents bugs where someone might accidentally delete an element from the middle of your history or your "undo" chain, which would break the logic of your program.
// In short, a Vector is a tool for storage, while a Stack is a tool for process control.

Monotonic Stack is a variant of stack applied using the Stack itself.
In a standard stack, you can push any value at any time. In a Monotonic Stack, you maintain a strict order (either entirely increasing or entirely decreasing) by popping elements that violate that order before you push a new one.

The Two Types:
1) Monotonic Increasing: The stack only contains elements in increasing order (e.g., 1, 3, 5, 8).
The Rule: Before pushing x, you must pop() everything that is greater than x.

2) Monotonic Decreasing: The stack only contains elements in decreasing order (e.g., 10, 7, 4, 2).
The Rule: Before pushing x, you must pop() everything that is smaller than x.

Where to use Stack for Questions : 
 1) Recursion Based (Not Usually but still)
 2) Nearest / Next Greater / Smaller Element	(By Monotonic Stack)
 3) Expressions Conversion (Infix , Prefix , Postfix)
 4) Expression Evaluation (Infix , Prefix , Postfix)
 5) Parenthesis Evaluation
 6) Backtracking (DFS)
 7) Undo / Redo Mechanisms 	(2 Stacks or doubly linked list better than deque )
 8) Browser History		(Doubly Linked List or Deque better)
 9) Syntax Parsing
10) String Reversal
11) Task Switching in OS
(String Related Questions are usually handled by Stack)
