//  Doubly Circular Linked List
// ============================================================
// Same as Doubly Linked List except:
//   - tail->next points back to head  (instead of nullptr)
//   - head->prev points back to tail  (instead of nullptr)
//   - There is no nullptr anywhere in the chain.
//   - Traversal must stop when we come back to head, NOT nullptr.
//
// Structure:
//   (tail) <-> [1] <-> [2] <-> [3] <-> [4] <-> (back to head)
//      ^___________________________________________________|
//
// Advantage over Singly Circular:
//   - pop_back() is O(1) because tail->prev gives the second-to-last node.
//   - Can traverse backwards just like doubly list.
//   - There is no STL for this in C++.
//   - It is a linear data structure.
// ============================================================

// We can implement a circular linked list as either doubly or singly.
// If we remove the loop , it becomes doubly or singly linked list.
// It has real world applications instead of typical questions.
// It acts like a circular queue (simulation / modulo array based).
// The applications of such a data structure can also be handled by a circular queue as well (or others).

Use doubly circular linked list when :
Rule: You need to loop endlessly AND go BACKWARDS.

1) Playlist (prev + next, loops back) : Previous song wraps to last song too
2) Advanced Round-Robin Scheduling : Need to go back to previous process
3) Circular Deque : Insert/delete both ends + wraps around
4) Game turn system (prev/next player) : Skip turn backwards or forwards
5) Calendar/Clock navigation : Wrap both ways (Dec → Jan, Jan → Dec)
6) Detecting & Removing Loops etc.
